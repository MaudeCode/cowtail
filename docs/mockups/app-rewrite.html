Rules

  • This page is the visual spec for COW-9, COW-12, COW-13, COW-14, COW-16, COW-17, COW-18, COW-19, COW-21, COW-22, COW-32 and COW-34. A ticket decides behaviour, data and API. This page decides layout, grouping, order and controls.
  • A section is a small uppercase mono label over rows split by hairlines. No card, panel or box encloses a section or a row, on web or iOS. Sheets, popovers, dialogs, banners and notifications are the only enclosed surfaces.
  • Every action is an icon button with an accessible name, and a tooltip on web. Text stays only on sign-in buttons, a question's answer options, a script action on an item, the submit of a sheet or dialog, and iOS notification actions.
  • A web list filters through one filter icon button. Search and pickers sit in the popup it opens, active filters show as removable chips, and the filter is part of the address.
  • Colour and type are the Cowtail dark palette, Space Grotesk and DM Mono, from web/src/index.css and the iOS theme system. Light mode and the other iOS theme keep this layout with their own palette.
  • Sample data is invented. A glyph in the source-icon position stands for that source's uploaded icon.
  • A control the app has today, and that no ticket removes, stays in the nearest section.
  • Drawn on iOS only, and the same on web: the snooze picker is a popover from the Snooze button, Upcoming is a section after "Hermes is on it" on Home, and the maintenance sheet is a dialog from the wrench button with its banner above "Needs you".
  • Drawn on web only, and the same on iOS, stacked in this order: item detail is header, timeline with evidence, metric graph, details, fix, past occurrences. Incident detail is header, timeline, postmortem, members.
  • Below 960 px wide the web columns stack in source order, left column first, and a nav link keeps its label on the current page only. Nothing scrolls sideways at 382 px.
